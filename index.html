Hướng dẫn

• Kho: sửa số lượng → Lưu. Đặt 0 = hết hàng (shop hiện "HẾT HÀNG").
• Mã giảm: tạo mã % hoặc số tiền (K).
• Thông báo: hiện popup khi khách vào shop.
• Cài đặt: Zalo, STK ngân hàng.
• Badge xanh GITHUB = dữ liệu lưu vĩnh viễn (không mất khi web ngủ).
• Badge vàng LOCAL = chưa cấu hình GitHub Token (dữ liệu có thể mất khi restart).
